Source Delivery range and cache prototype

This demo asks one question: can Shutter use one stable, locator-free cache entry for a complete Source, let Cloudflare slice byte ranges from it, and stream cold or oversized ranges from the origin without copying originals into the Rendition Store?

Prototype verdict

Keep one complete-object Cache API entry, keyed by Space and Source identity. A warm entry can answer full, conditional, and single-range requests. A cold range goes straight to the origin and is not stored, because Cloudflare rejects 206 responses in cache.put(). Complete 200 responses up to Cloudflare's 512 MB Cache API limit may populate the entry. Larger objects still stream from the origin. Private requests authorize before every cache lookup. Source Purge removes the stable entry by its existing Source tag. No original enters R2.
